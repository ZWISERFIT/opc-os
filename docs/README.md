# OPC-OS Documentation

## Quick Start

```bash
git clone https://github.com/ZWISERFIT/opc-os.git
cd opc-os
npm install
```

## Core Modules

| Module | Path | Description |
|--------|------|-------------|
| Runtime | `src/runtime/` | Agent lifecycle management |
| Event | `src/event/` | Cross-agent event bus |
| Memory | `src/memory/` | Persistent memory & knowledge graph |
| Governance | `src/governance/` | Auditable governance engine |
| Pipeline | `src/pipeline/` | Data pipeline & cross-framework bridge |
| Utils | `src/utils/` | Shared utilities |
